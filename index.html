    ABOUT THE COLLECTION

    Every song has a world inside.

    The personal music collection from vislupus/ai-songs. Artwork, titles, artist credits, and lyrics come from the MP3 files themselves. Style notes come from matching song documents in the repository.

    Listen your way

    Play a song or start the collection. Use the queue, shuffle, repeat, volume, and seek controls. Browsing, searching, saving favorites, and opening lyrics do not restart the music. New cards are added below the existing ones.

    Space play / pause · ← / → seek 5 seconds · M mute · / search · Esc close a dialog. Shortcuts leave text fields and focused buttons alone.

    Favorites stay with you, in this browser

    Hearts are saved locally for this website. They are not public likes and are not synced between devices or browsers. Clearing site data removes them. Some browsers restrict storage inside embedded players; open the full collection to keep favorites reliably.

    Lyrics and artwork

    The reader supports ID3v2.2, v2.3, and v2.4. Embedded lyrics take priority; matching song notes provide a fallback if no lyrics were saved in the audio file. Lyrics stay in their original language. Timestamped playback is available only when actual synchronized lyric tags are present. Songwriting directions are not treated as verified timings.

    Share a song or embed a player

    Every song has its own direct link. The Share button can also create an iframe player for another website, optionally starting at the current playback position. Shared pages wait for the listener to press play. Publish this file before using public links. Sites must allow iframe embeds. Social previews use the collection title; this standalone file does not generate separate server-rendered preview cards for each song.

    Publish with GitHub Pages

    1. Put this file in the repository root as index.html.
    2. Open Settings → Pages in GitHub.
    3. Select Deploy from a branch → main → / (root) and save.

    The expected address is vislupus.github.io/ai-songs/. You can also host the HTML file elsewhere and update “Website address” in the Share dialog.

    New music, without rebuilding

    The page checks the repository for new MP3 files and matching song notes. The Refresh button checks again. Metadata is read in small requests and cached locally. A built-in catalog keeps the collection visible if the API is temporarily unavailable. Audio streams from the repository and needs an internet connection; this file does not contain the audio recordings.
